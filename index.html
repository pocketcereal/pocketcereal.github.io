POCKETCEREAL AUDIO DISCOVERY SYSTEMS REV 2026.07
UNITS CONTACT GITHUB

Audio sorted by ideas, not by metadata.

Media tools sort by title, artist, and category — whatever happened to ship with the file. pocketcereal builds the other kind: a player that runs on three platforms, a federated API across open music and podcast archives, and inference that finds structure inside media rather than around it.

UNIT SP-01 · AGGREGATION

Spoons

One GraphQL schema across music, podcasts, and audiobooks, fanning out to five open archives — MusicBrainz, Audius, Jamendo, PodcastIndex, and LibriVox. Ask a single source or all of them in one request; streaming links resolve per archive behind a normalized type, so nothing downstream needs to know where an item came from. The schema is the product — the hard part is agreeing what an artist, an episode, and a track are when five catalogues disagree.

github.com/pocketcereal/spoons-api

UNIT PC-02 · CLIENT

PocketCereal

A music and podcast player built once and shipped to iOS, Android, and the web. Background playback with lock-screen transport, a queue that auto-advances, follow lists that sync, and history that picks up mid-episode. Random mode drops you at a random position in a random episode — discovery by accident, which turns out to beat another recommendation row.

UNIT PC-03 · SERVICES

Discovery API

The search and discovery service behind the player. The specification is the source of truth for the contract, so the client is generated from the spec rather than from documentation that drifts a release behind the code.

UNIT CR-04 · INFERENCE

Cereal

A continuous monitor, and a testbed for how agents should be structured. Detection runs constantly over active sources and accumulates structured events before any question is asked. At query time an orchestrator composes narrow capabilities — detection lookup, object tracks, evidence retrieval, visual validation — so the expensive model validates one claim against one bounded window instead of streaming over everything. A claim cannot be made without evidence attached to it.
